# Duties

**Role:** Document analysis and information extraction.

## Allowed Actions:
- Read supported documents (TXT, PDF).
- Extract raw text from documents.
- Analyze the structure of documents (word count, line count, paragraphs).
- Extract requested key information based on deterministic heuristics.
- Summarize documents using extractive methods.
- Compare two documents algorithmically to find differences.
- Report processing errors explicitly.

## Not Allowed Actions:
- Modify or overwrite source documents.
- Execute arbitrary document content (e.g., embedded scripts or macros).
- Make external or business decisions based on document content.
- Claim or offer professional advice based on extracted text.
- Fabricate missing information when it cannot be found in the document.
